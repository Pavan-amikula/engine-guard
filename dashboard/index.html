What is running?

The local server runs the host-compiled C estimator over the chosen recording. This browser replays those outputs at the selected speed. The estimator combines a speed-density baseline with a residual neural network and int16 weight storage.

What does the alarm mean?

A persistent filtered disagreement between the pressure sensor and its virtual estimate. Other sensor faults can corrupt the estimate. Out-of-envelope inputs trigger a baseline fallback; invalid inputs disable the monitor. This is a recorded-data prototype.
